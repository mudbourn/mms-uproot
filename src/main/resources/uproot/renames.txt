# Names that changed between Minecraft 1.21.11 and 26.3. Names only, in Mojang terms.
# class OLD NEW                    renames one class (nested classes follow their outer class, unless a rule
#                                  names the nested class itself)
# package OLD NEW                  renames a package prefix
# method OWNER OLD NEW [ARGS|DESC] renames a method on OWNER and on everything extending or implementing it;
#                                  OWNER may be * for any owner. ARGS is an argument count, DESC a descriptor
#                                  in 1.21.11 names; either keeps unrelated overloads out
# field OWNER OLD NEW              renames a field, likewise down the hierarchy; OWNER may be *
# fieldowner OLD NEW               static constants of OLD now live in NEW
# ctor OWNER OLDDESC NEWDESC POS=FOWNER.FIELD:FDESC
#                                  a constructor gained a parameter. Calls (invokespecial) push the static field
#                                  FOWNER.FIELD as argument POS. OWNER and descriptors are 26.3 names. Only an
#                                  object-typed field, placed last or just before a one-slot last argument.
#                                  POS=#N pushes the int N instead, as the last argument.
# fieldmove OWNER NAME NEWOWNER NEWNAME
#                                  a static field read (getstatic) of OWNER.NAME is read from NEWOWNER.NEWNAME
#                                  instead, same descriptor. All four are 26.3 names, NAME after any field rule.
#                                  For constants that 26.3 dropped and a class of Uproot's own now holds
# callmove OWNER NAME DESC NEWOWNER NEWNAME
#                                  a static call (invokestatic) of OWNER.NAME with descriptor DESC goes to NEWOWNER.NEWNAME
#                                  with the same descriptor. All 26.3 names, DESC as the call site has it after renaming.
#                                  For methods whose signature changed and that a class of Uproot's own now answers.
#                                  Static methods are inherited, so a call through a subclass of OWNER matches too
# calldesc OWNER NAME OLDDESC NEWDESC
#                                  a virtual or interface call of OWNER.NAME with OLDDESC now has NEWDESC (same method,
#                                  erased differently). Also matches calls through a subclass of OWNER and method
#                                  references. If the return type changed to a wider one, a checkcast to the old one
#                                  follows the call. All 26.3 names.
#                                  A lambda made for that interface method gets NEWDESC as its erased method type too.
#                                  e.g. calldesc net/minecraft/world/level/block/state/BlockState is (Lnet/minecraft/world/level/block/Block;)Z (Ljava/lang/Object;)Z
# callinst OWNER NAME DESC HELPER.method
#                                  an instance call (invokevirtual or invokeinterface) of OWNER.NAME with DESC becomes
#                                  invokestatic HELPER.method with DESC plus OWNER as a new first parameter. HELPER is
#                                  an internal class name, a dot and the method name. Matches subclasses of OWNER
#                                  and method references, but not super calls.
#                                  e.g. callinst net/minecraft/world/entity/player/Player displayClientMessage (Lnet/minecraft/network/chat/Component;Z)V info/mudbourn/mmsuproot/shim/block/LegacyBlocks.displayClientMessage
#                                  An optional NEWDESC after NEWNAME is the descriptor the new target has, when only the return type
#                                  differs (a result that is now a wider type, as long as the mod uses it as that type).
# fieldget OWNER NAME METHOD     a read (getfield) of the field OWNER.NAME is a call of OWNER.METHOD() now, which returns the same
#                                  type; the field is private or gone. OWNER is the 26.3 name the read names, no subclasses.
# castadapt CLASS HELPER.method   a checkcast to CLASS (26.3 name) becomes invokestatic HELPER.method(Object)CLASS. For a value
#                                  whose type changed behind a generic, such as a registry entry that is now another class.
#                                  e.g. castadapt info/mudbourn/mmsuproot/shim/noise/NoiseParameters info/mudbourn/mmsuproot/shim/noise/NoiseParameters.cast
# bridge OWNER NAME OLDDESC NEWDESC
#                                  a mod class that extends or implements OWNER (the 26.3 type that declares NEWDESC)
#                                  overrides NAME with OLDDESC, and NEWDESC only added parameters after the old ones
#                                  (object parameters may also be narrower). The class gets a NEWDESC method that drops
#                                  the added arguments and calls the OLDDESC one. A super call of NAME with OLDDESC
#                                  inside the OLDDESC override goes to the NEWDESC of the super class, passing
#                                  null, 0 or false for the added arguments and a checkcast for narrowed ones.
#                                  Same return type. A class that declares NEWDESC itself is left alone.
#                                  The rule also serves mixins: an @Inject handler of a mixin whose target class extends or
#                                  implements OWNER, and that names NAME, lists the old parameters before its callback; it
#                                  gets the added parameters inserted before the callback and the handler is wrapped so
#                                  its body runs unchanged (see remap.MixinParams).
#                                  A lambda or method reference for a functional interface that extends or is OWNER gets the same treatment: it is
#                                  made for NEWDESC and runs through a static method of the mod class that drops the added arguments.
#                                  e.g. bridge net/minecraft/world/level/block/BonemealableBlock performBonemeal (Lnet/minecraft/server/level/ServerLevel;Lnet/minecraft/util/RandomSource;Lnet/minecraft/core/BlockPos;Lnet/minecraft/world/level/block/state/BlockState;)V (Lnet/minecraft/server/level/ServerLevel;Lnet/minecraft/util/RandomSource;Lnet/minecraft/core/BlockPos;Lnet/minecraft/world/level/block/state/BlockState;Lnet/minecraft/world/level/block/BonemealSource;)V
# injectat OWNER NAME DESC NEWOWNER NEWNAME NEWDESC
#                                  a mixin @At target string (Lowner;name(desc)ret) that names OWNER.NAME with DESC now names
#                                  NEWOWNER.NEWNAME with NEWDESC. All 26.3 names, DESC as the string has it after renaming.
#                                  For injections whose call moved to another method; pair it with a method rule for the
#                                  injected method itself, whose handler arguments and locals must still fit.
# typesonly CLASS                 the class rule for CLASS (1.21.11 name) holds for types and signatures only: the 26.3 class is not the old
#                                  class's stand-in for calls. The offline scan reports every call of a member of CLASS as a real gap.
# interface CLASS                 CLASS (an internal name of another mod's library, not the game's: those are read from the game) was a class in
#                                  1.21.11 and is an interface now, so calls of its methods use invokeinterface. e.g. interface eu/pb4/placeholders/api/PlaceholderContext
# ctoradapt OWNER OLDDESC NEWDESC HELPER.method
#                                  a constructor whose arguments change in more ways than ctor can say. Calls
#                                  (invokespecial, so both new X(...) and super(...)) and X::new references pass the
#                                  old arguments to the static HELPER.method(OLDDESC arguments) that returns the new
#                                  ones as an Object[]; each element is cast (or unboxed) to its NEWDESC type.
#                                  e.g. ctoradapt net/minecraft/world/level/block/grower/TreeGrower (Ljava/lang/String;F...)V (Ljava/lang/String;...)V info/mudbourn/mmsuproot/shim/block/LegacyBlocks.treeGrowerArgs
# instanceadapt CLASS HELPER.method
#                                  an instanceof test of CLASS (26.3 name) becomes invokestatic HELPER.method(Object)Z. For a class that 26.3
#                                  dropped and whose meaning a check can still answer (an axe is an item in the axes tag).
#                                  e.g. instanceadapt net/minecraft/world/item/AxeItem info/mudbourn/mmsuproot/shim/item/LegacyTools.isAxe
# inherited TARGET NAME DESC [SUPERDESC]
#                                  a mixin class targeting TARGET has injectors on NAME DESC, which 26.3's TARGET no longer
#                                  declares but a superclass does. Mixin cannot inject into an inherited method, so the mixin
#                                  class gets a public override NAME DESC that calls the superclass's method; Mixin merges it
#                                  into TARGET and the injectors land on it. DESC is what the mixin names (1.21.11's shape),
#                                  SUPERDESC what the declaring superclass has (its erased generics), DESC when omitted. When
#                                  they differ, a bridge method SUPERDESC that casts and calls the DESC one is added too, as
#                                  javac would have, so the game's call reaches the injectors. TARGET and descriptors are 26.3
#                                  names. Skipped when TARGET declares the method itself.
#                                  e.g. inherited net/minecraft/client/model/monster/zombie/DrownedModel setupAnim (Lnet/minecraft/client/renderer/entity/state/ZombieRenderState;)V (Lnet/minecraft/client/renderer/entity/state/HumanoidRenderState;)V
# annotation OLD NEW               text inside a mixin annotation string (after the names were mapped, 26.3 names) becomes NEW. For a target method
#                                  whose descriptor changed, where injectat (a call in an @At) does not reach.
# handler MIXINCLASS HANDLERNAME NEWDESC ARGMAP
#                                  the injector handler HANDLERNAME of the mod's mixin class MIXINCLASS (its own internal name) was
#                                  written for a target whose parameters changed in ways bridge cannot say: removed, reordered or retyped.
#                                  NEWDESC is the handler's descriptor in 26.3: the target's parameters, then the callback, void return. The
#                                  old handler loses its annotations and becomes private; a new method with NEWDESC takes them and calls it
#                                  (see remap.MixinParams). ARGMAP has one comma-separated entry per old parameter before the old callback
#                                  (which must be last): the index of the new parameter that gives the value (cast when the type differs
#                                  in class only), null or false for the default of the parameter's type (null, 0 or false), or
#                                  pkg/Helper.method, an internal class name, a dot and a static no-argument method of Uproot's own whose
#                                  return type is the old parameter's. "-" for a handler that had no parameters but the callback. A method
#                                  named with its old descriptor in the annotation is rewritten to the target's new parameters.
#                                  Choose entries after reading which old parameters the handler body uses; an unused one may default.
#                                  e.g. handler net/conczin/immersive_optimization/mixin/client/LevelRendererMixin immersiveOptimization$render (Lcom/mojang/blaze3d/resource/GraphicsResourceAllocator;ZLnet/minecraft/client/renderer/state/level/CameraRenderState;Lcom/mojang/renderpearl/api/buffers/GpuBufferSlice;Lorg/joml/Vector4f;ZZLorg/spongepowered/asm/mixin/injection/callback/CallbackInfo;)V 0,null,1,2,null,3,4,5
#                                  An optional field locals=I,J,... (null for a default) says where each local variable that the old handler
#                                  captured after its callback comes from, as the index of the new parameter; NEWDESC then lists the
#                                  captured locals of the 26.3 target in order, as Mixin wants them. Without it a captured local is found again by
#                                  type, the last unused parameter of that type, which only fits when the types are all different.
#                                  An optional sixth field if=pkg/Helper.method names a static boolean method of Uproot's own that gets the target's
#                                  parameters (those before the callback) and says whether the handler runs; for a hook whose old target was a
#                                  case of the new one. The handler must return nothing.
#                                  (a MixinExtras wrap operation handler may also use this: the Operation takes the place of the callback, and the values
#                                  captured after it (the enclosing method's parameters, all of them in 26.3 as MixinExtras wants them) are found again by type. Its method= string is then not touched; use annotation for it.)
# retbridge OWNER NAME DESC RET   a class that extends or implements OWNER and declares NAME DESC also gets NAME with the same arguments returning RET (a type
#                                  descriptor the declared return type extends), calling it: what javac makes for a covariant return. For a method that a
#                                  rename turned into one the game calls with a wider return type.
#                                  e.g. retbridge net/minecraft/world/level/storage/loot/predicates/LootItemCondition codec ()Linfo/mudbourn/mmsuproot/shim/compat/LegacyLootConditionType; Lcom/mojang/serialization/MapCodec;
# implbridge OWNER OLDNAME OLDDESC NEWNAME NEWDESC [HELPER.method]
#                                  a class that extends or implements OWNER and declares OLDNAME OLDDESC (what 1.21.11 called an abstract method of
#                                  OWNER, as the class has it after renaming) also gets NEWNAME NEWDESC, the abstract method of 26.3, with the same
#                                  arguments, calling it. HELPER.method (static, takes the old return type and returns the new one) converts the result.
#                                  NEWDESC may have more parameters than OLDDESC when the extra ones come first (a level the old method never took); the
#                                  bridge drops them.
#                                  e.g. implbridge net/minecraft/server/packs/repository/Pack$ResourcesSupplier openPrimary (Lnet/minecraft/server/packs/PackLocationInfo;)Lnet/minecraft/server/packs/PackResources; openMetadata (Lnet/minecraft/server/packs/PackLocationInfo;)Lnet/minecraft/server/packs/PackMetadataResources;
# invokerparam MIXINCLASS NAME OLDDESC EXTRA
#                                  the @Invoker method NAME (descriptor OLDDESC) of the mod's mixin interface MIXINCLASS targets a method that gained
#                                  trailing parameters, EXTRA (parameter types in descriptor syntax). The interface method takes them too, and every
#                                  call of it in the mod passes the zero value of each (false, 0, null).
#                                  e.g. invokerparam io/wispforest/owo/mixin/ui/access/GuiGraphicsExtractorAccessor owo$tooltip (Lnet/minecraft/client/gui/Font;Ljava/util/List;IILnet/minecraft/client/gui/screens/inventory/tooltip/ClientTooltipPositioner;Lnet/minecraft/resources/Identifier;)V Z
# mixinmethod MIXINCLASS HANDLER METHOD
#                                  the injector HANDLER of the mod's mixin class MIXINCLASS (its own internal name) names its target method by an intermediary name,
#                                  which two overloads of 26.3 now share, so the @Inject can no longer tell them apart: METHOD (name and descriptor, 26.3
#                                  names) replaces what its method= says. e.g. mixinmethod io/wispforest/owo/mixin/ext/ItemStackMixin deriveComponents4 applyComponents(Lnet/minecraft/core/component/DataComponentMap;)V
# mixintarget MIXINCLASS OLDTARGET NEWTARGET
#                                  the mixin class MIXINCLASS (its own internal name) names OLDTARGET in its @Mixin, and what it injects
#                                  into lives in NEWTARGET now (a class that took over part of the old one). Both are 26.3 names. Its
#                                  shadows and handlers are then read against NEWTARGET; pair it with method and handler rules where the
#                                  members changed too.
#                                  e.g. mixintarget dev/liqw/locatorborder/mixin/GuiMixin net/minecraft/client/gui/Gui net/minecraft/client/gui/Hud
# mixinannotation MIXINCLASS OLD NEW
#                                  as annotation, for the annotation strings of the one mixin class MIXINCLASS only (its own internal name),
#                                  which a text of the same shape in another mod's mixin must not be changed by. e.g. the name of a target
#                                  method that the class's new target (see mixintarget) declares under another name.
#                                  A mixin that extends the class its mixintarget names gets Object as its superclass, which Mixin demands.
# mixinalso MIXINCLASS NEWTARGET   adds NEWTARGET (a 26.3 class) to the targets in the @Mixin of MIXINCLASS (its own internal name), for a mixin whose
#                                  injectors now belong to two classes (one of them moved, the others stayed). Each injector runs where it finds its target;
#                                  name the owner in the method string (see mixinmethod) so that a method both classes have is only hooked in one.
#                                  Shadows are not read against the added class, so the mixin should have none the class lacks.
# superdefault OLDSUPER NEWSUPER  every mod class whose direct superclass is OLDSUPER (a 26.3 name) extends NEWSUPER instead, as super does for one class.
#                                  For a base class whose 1.21 shape a stand-in answers; NEWSUPER must extend OLDSUPER and have its constructors.
#                                  e.g. superdefault net/minecraft/client/renderer/entity/EntityRenderer info/mudbourn/mmsrendercommon/client/legacy/LegacyEntityRenderer
# super CLASS NEWSUPER             a mod class (its own name, as it is in the mod) extends NEWSUPER, an internal name, where it extended its own
#                                  superclass; NEWSUPER must extend that superclass and have its constructors. The class's invokespecial calls
#                                  of the old superclass (constructors, super.m()) go to NEWSUPER. For a mod class whose superclass lost methods
#                                  that the class overrides, which a stand-in superclass can keep.
