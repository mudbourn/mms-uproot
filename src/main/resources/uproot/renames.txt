# Names that changed between Minecraft 1.21.11 and 26.3. Names only, in Mojang terms.
# class OLD NEW                    renames one class (nested classes follow their outer class, unless a rule
#                                  names the nested class itself)
# package OLD NEW                  renames a package prefix
# method OWNER OLD NEW [ARGS|DESC] renames a method on OWNER and on everything extending or implementing it;
#                                  OWNER may be * for any owner. ARGS is an argument count, DESC a descriptor
#                                  in 1.21.11 names; either keeps unrelated overloads out
# field OWNER OLD NEW              renames a field, likewise down the hierarchy; OWNER may be *
# fieldowner OLD NEW               static constants of OLD now live in NEW
# ctor OWNER OLDDESC NEWDESC POS=FOWNER.FIELD:FDESC
#                                  a constructor gained a parameter. Calls (invokespecial) push the static field
#                                  FOWNER.FIELD as argument POS. OWNER and descriptors are 26.3 names. Only an
#                                  object-typed field, placed last or just before a one-slot last argument.
#                                  POS=#N pushes the int N instead, as the last argument.
# fieldmove OWNER NAME NEWOWNER NEWNAME
#                                  a static field read (getstatic) of OWNER.NAME is read from NEWOWNER.NEWNAME
#                                  instead, same descriptor. All four are 26.3 names, NAME after any field rule.
#                                  For constants that 26.3 dropped and a class of Uproot's own now holds
# callmove OWNER NAME DESC NEWOWNER NEWNAME
#                                  a static call (invokestatic) of OWNER.NAME with descriptor DESC goes to NEWOWNER.NEWNAME
#                                  with the same descriptor. All 26.3 names, DESC as the call site has it after renaming.
#                                  For methods whose signature changed and that a class of Uproot's own now answers.
#                                  Static methods are inherited, so a call through a subclass of OWNER matches too
# calldesc OWNER NAME OLDDESC NEWDESC
#                                  a virtual or interface call of OWNER.NAME with OLDDESC now has NEWDESC (same method,
#                                  erased differently). Also matches calls through a subclass of OWNER and method
#                                  references. If the return type changed to a wider one, a checkcast to the old one
#                                  follows the call. All 26.3 names.
#                                  e.g. calldesc net/minecraft/world/level/block/state/BlockState is (Lnet/minecraft/world/level/block/Block;)Z (Ljava/lang/Object;)Z
# callinst OWNER NAME DESC HELPER.method
#                                  an instance call (invokevirtual or invokeinterface) of OWNER.NAME with DESC becomes
#                                  invokestatic HELPER.method with DESC plus OWNER as a new first parameter. HELPER is
#                                  an internal class name, a dot and the method name. Matches subclasses of OWNER
#                                  and method references, but not super calls.
#                                  e.g. callinst net/minecraft/world/entity/player/Player displayClientMessage (Lnet/minecraft/network/chat/Component;Z)V info/mudbourn/mmsuproot/shim/block/LegacyBlocks.displayClientMessage
# bridge OWNER NAME OLDDESC NEWDESC
#                                  a mod class that extends or implements OWNER (the 26.3 type that declares NEWDESC)
#                                  overrides NAME with OLDDESC, and NEWDESC only added parameters after the old ones
#                                  (object parameters may also be narrower). The class gets a NEWDESC method that drops
#                                  the added arguments and calls the OLDDESC one. A super call of NAME with OLDDESC
#                                  inside the OLDDESC override goes to the NEWDESC of the super class, passing
#                                  null, 0 or false for the added arguments and a checkcast for narrowed ones.
#                                  Same return type. A class that declares NEWDESC itself is left alone.
#                                  e.g. bridge net/minecraft/world/level/block/BonemealableBlock performBonemeal (Lnet/minecraft/server/level/ServerLevel;Lnet/minecraft/util/RandomSource;Lnet/minecraft/core/BlockPos;Lnet/minecraft/world/level/block/state/BlockState;)V (Lnet/minecraft/server/level/ServerLevel;Lnet/minecraft/util/RandomSource;Lnet/minecraft/core/BlockPos;Lnet/minecraft/world/level/block/state/BlockState;Lnet/minecraft/world/level/block/BonemealSource;)V
# ctoradapt OWNER OLDDESC NEWDESC HELPER.method
#                                  a constructor whose arguments change in more ways than ctor can say. Calls
#                                  (invokespecial, so both new X(...) and super(...)) and X::new references pass the
#                                  old arguments to the static HELPER.method(OLDDESC arguments) that returns the new
#                                  ones as an Object[]; each element is cast (or unboxed) to its NEWDESC type.
#                                  e.g. ctoradapt net/minecraft/world/level/block/grower/TreeGrower (Ljava/lang/String;F...)V (Ljava/lang/String;...)V info/mudbourn/mmsuproot/shim/block/LegacyBlocks.treeGrowerArgs
