# Names that changed between Minecraft 26.1/26.2 and 26.3, for mods built for those versions. They already use Mojang names, so this
# table holds only what 26.3 changed since; Uproot applies it to them in place of renames.txt, in the same format (see the top of that file).
# Which mods count as built for an older 26.x: those whose Minecraft range excludes 26.3 but admits 26.1 or 26.2, and those with an open range
# whose classes name something only the older versions have (see ModSource.OLDER_26).

# The GPU abstraction moved into com.mojang.renderpearl. GpuBufferSlice is the one class a mod names on its own: mixin targets of the
# projection and level render calls take it as a parameter.
